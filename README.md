# Match Your Colors

Match Your Colors now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Match Your Colors's C source is in
[`src/components/match_your_colors`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/match_your_colors).

The standalone Lua mod (v1.5 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/MatchYourColors/tree/legacy) branch. Its releases and tags are unchanged.
